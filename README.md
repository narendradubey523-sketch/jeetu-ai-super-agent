# JEETU AI Super Agent — Starter

Hindi-first Next.js starter UI with 12 agent workspaces and an admin overview.

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Run `npm run dev`
4. Open http://localhost:3000

## Deploy
Push the project files to GitHub, import the repository in Vercel, and deploy with the default Next.js settings.

## Important status
This is a UI starter only. Real AI requests, authentication, authorization, Supabase database, payment handling, audit logs and production security are not implemented. Do not put API secrets in browser code or commit `.env` files. Add secrets only in server-side hosting environment settings after implementing the corresponding server routes.
